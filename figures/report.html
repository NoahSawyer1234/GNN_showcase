How to read this

  • Same data for every model. The graph networks also see the links between nodes; the plain GBM sees only each node's own features. Two GBM rows are also given graph information: "GBM + neighbour features" gets the average of each node's neighbours as extra columns, and "GBM + GAE" gets embeddings from a graph autoencoder, a graph network trained without labels to reconstruct the links. Together they separate "does the graph help?" from "does a graph network help?".
  • Wildfire has no autoencoder row: every area has the same grid of links, so there is no structure to learn.
  • Spread. Dots are repeated training runs with different random seeds. The GBM is deterministic here, so its dots coincide. The spread does not include test-set sampling noise, so small gaps between models should not be over-read; "about level" in the cards marks gaps under 0.01 (or twice the seed spread).
  • Medicare. Linked providers are no more likely to share a fraud label than random pairs, so the graph adds little; the plain GCN also averages away each provider's own features.
